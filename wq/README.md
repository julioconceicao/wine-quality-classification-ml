# Wine Quality Classification with Machine Learning

Projeto de classificação da qualidade de vinhos a partir de características físico-químicas, desenvolvido para o Tech Challenge - Fase 2 da Pós-Tech Data Analytics (FIAP).

## Objetivo

Prever se um vinho é de alta qualidade (`quality >= 7`) ou de baixa/média qualidade (`quality < 7`) com base em suas características físico-químicas.

## Estrutura do projeto

```text
wine-quality-classification-ml/
├── data/        # Base de dados utilizada
├── notebooks/   # Análise exploratória e modelagem
├── src/         # Scripts reutilizáveis de preparação e modelagem
├── results/     # Gráficos, métricas e artefatos dos modelos
├── requirements.txt
└── README.md
```

## Próximas etapas

1. Adicionar a base de dados em `data/`.
2. Desenvolver a EDA e a modelagem em `notebooks/`.
3. Extrair rotinas reutilizáveis para `src/`.
4. Salvar gráficos e métricas finais em `results/`.
